# BioTrack - Personal Health Informatics Suite
Eine modulare Java-Desktop-Anwendung zur Analyse und Visualisierung persönlicher Biosignale und Vitaldaten (Wearable-Exporte von Apple Health, Garmin etc.).
## Geplante Module
1. **Cardio:** Herzfrequenz-Zonen-Rechner & Belastungs-Profiler
2. **Infekt-Radar:** Ruhepuls-Trend & statistische Anomalie-Erkennung
3. **Schlaf-Analyse:** Schlafphasen-Architektur & Schlafeffizienz
4. **ETL-Pipeline:** Lokaler Sanitizer & Parser für Wearable-Rohdaten (XML/CSV)
